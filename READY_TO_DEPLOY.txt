================================================================================
TROUBLESHOOTING
================================================================================

EXECUTION POLICY ERROR
  Error: "cannot be loaded because running scripts is disabled"
  Solution: Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

API KEY NOT WORKING
  Error: "Unauthorized" or "Invalid API key"
  Solution: Verify API key from https://dashboard.render.com/account/api-tokens

DATABASE CONNECTION FAILS
  Error: "Cannot connect to database"
  Solution: Wait a few minutes for database to be ready

OAUTH REDIRECT URI MISMATCH
  Error: "Redirect URI mismatch"
  Solution: Check redirect URIs in Google Cloud Console match exactly

WEBRTC NOT CONNECTING
  Error: "Cannot establish peer connection"
  Solution: Check CORS_ORIGIN is set correctly
